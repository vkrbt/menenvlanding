# Выгрузки для отчёта

Сюда кладутся файлы из панелей вебмастера и Метрики. Их читает `scripts/seo-report.py` и сводит в таблицу по кластерам.

Файлы в этой директории **не коммитятся** — они попадают в `.gitignore`, чтобы не тащить в репозиторий сырые выгрузки. Отчёт по ним пишется в [../measurement.md](../measurement.md).

---

## Что выгружать

| Откуда | Что | Как назвать | Периодичность |
|---|---|---|---|
| Яндекс.Вебмастер → Поисковые запросы → Группы | Показы, клики, средняя позиция по URL | `webmaster-YYYY-MM-DD.csv` | Раз в контрольный период |
| Яндекс.Вебмастер → Индексирование → Страницы в поиске | Список страниц в поиске | `webmaster-index-YYYY-MM-DD.csv` | Раз в контрольный период |
| Яндекс.Метрика → Отчёты → Содержание → Страницы входа | Визиты и достижения целей по URL | `metrika-YYYY-MM-DD.csv` | Раз в контрольный период |
| Google Search Console → Результаты поиска → Страницы | Показы, клики, позиция по URL | `gsc-YYYY-MM-DD.csv` | Раз в контрольный период |

Дата в имени файла — дата выгрузки, не начало периода. Старые файлы не удалять: по ним видна динамика.

---

## Формат

Скрипт понимает CSV и TSV, разделитель определяет сам. Заголовок ищется в первых десяти строках — преамбула вида «Выгрузка Яндекс.Вебмастер / Период: …» не мешает.

Колонки сопоставляются по названию, а не по позиции. Понимаются такие варианты:

| Что | Допустимые заголовки |
|---|---|
| Адрес | `URL`, `Адрес`, `Страница`, `Page`, `Адрес страницы`, `Landing page` |
| Показы | `Показы`, `Показов`, `Impressions` |
| Клики | `Клики`, `Кликов`, `Переходы`, `Clicks` |
| Позиция | `Позиция`, `Средняя позиция`, `Position`, `Avg. position` |
| Визиты | `Визиты`, `Визитов`, `Сеансы`, `Visits`, `Sessions` |
| Цели | `Достижения цели`, `Достижения целей`, `Конверсии`, `Goals`, `Conversions` |

Порядок колонок значения не имеет, лишние колонки игнорируются. Числа с пробелами-разделителями разрядов и с запятой вместо точки читаются корректно.

Если колонки не распознались — скрипт скажет об этом прямо и не станет ничего выдумывать. В таком случае достаточно переименовать заголовок в файле под один из вариантов выше.

## Как читать вывод

```
Кластер                       Стат  URL    Показы   Клики    CTR    Поз  Визиты   Цели
```

- **Стат** — сколько статей в кластере всего (из `content/clusters.json`)
- **URL** — по скольким из них есть данные. Разрыв между «Стат» и «URL» показывает непроиндексированные или невидимые материалы
- **Кластеры без данных** — перечисляются отдельным списком. Это первые кандидаты в отстающие
- **URL вне кластеров** — страницы, не привязанные ни к одному кластеру: лендинг, `/vstrecha`, `/book`, рубрики

Привязка URL к кластеру идёт через `content/clusters.json`. Если статья появилась, а в выводе её нет — проверь, что она внесена в `seo/_core_data.py` и выполнен `python3 seo/gen_clusters.py`.
