## 1. Цель и как понять, что она достигнута

Вывести sreda.men в органическую выдачу Яндекса и Google по запросам русскоязычных мужчин и обеспечить поток заявок на встречи силами контента, без бюджета.

| # | Критерий | Целевое значение | Статус на 2026-07-29 |
|---|---|---|---|
| 1 | Кластеры закрыты целиком (pillar + сателлиты, с перелинковкой) | **18** | 0 из 18. Pillar есть у 9 кластеров, но ни один кластер не закрыт полностью |
| 2 | Доля материалов с органическими показами | ≥60%, **раздельно по Яндексу и Google** | Яндекс — есть индексация, показы не замерены; Google — 0 проиндексировано |
| 3 | Измеренная конверсия страницы встречи в заявку | Замер существует и осмыслен | Страница создана 2026-07-29, целей в Метрике ещё нет |
| 4 | Measurement-отчёт с решениями по отстающим | Ведётся по контрольным точкам | Каркас готов, КТ-1 — 2026-08-26 |

**Критерий 1 расходится с ТЗ, и это зафиксировано.** ТЗ требует не менее 25 кластеров. Инвентаризация фазы 3 показала: честно набирается 18. Причины и дорожная карта добора до 25 — [decisions.md](decisions.md), запись Р-003. Коротко: четыре самые ёмкие темы ниши держат клиники и психологические маркетплейсы, а дотянуть до 25 дроблением означало бы спроектировать каннибализацию заранее.

## 4. Чек-лист качества материала

Прогоняется перед публикацией каждого материала. Все пункты проверяемые: по каждому можно ответить «да» или «нет», не рассуждая.

| # | Пункт | Как проверяется |
|---|---|---|
| К1 | Целевой запрос присутствует **дословно** в `H1` | Поиск строки запроса в первом заголовке |
| К2 | Целевой запрос присутствует **дословно** в первом абзаце | Поиск строки в первом абзаце тела |
| К3 | Содержательных `H2` — **от 4 до 7** | Подсчёт `^## `, без `## Частые вопросы` и `## Читать дальше` |
| К4 | Внутренних ссылок `](/blog/…)` — **не менее 3** | Подсчёт вхождений |
| К5 | Есть ссылка на **pillar своего кластера** | Slug pillar из `content/clusters.json` встречается в теле |
| К6 | Есть **не менее 1 ссылки** на материал кластера `format` (правило П4) | Любой slug кластера `format` встречается в теле |
| К7 | Ссылок на материалы **чужих** кластеров — **не более 2**, не считая обязательной ссылки на кластер `format` из К6 | Подсчёт по `content/clusters.json` за вычетом ссылки К6 |
| К8 | Все внутренние ссылки ведут на **существующие** slug'и | `python3 scripts/seo-check.py` |
| К9 | Блок `<!-- CTA -->` присутствует | Поиск маркера |
| К10 | В блоке `## Частые вопросы` — **не менее 3** пар вопрос-ответ | Подсчёт пар |
| К11 | Блок `## Читать дальше` содержит **от 2 до 4** позиций | Подсчёт |
| К12 | Часть `title` до ` | Мужская среда` — **не более 60 символов** | Длина подстроки до разделителя |
| К13 | `description` — **от 120 до 170 символов** | Длина строки фронтматтера |
| К14 | Целевой запрос **не занят** другим материалом | `target_query` уникален, проверяет `seo-check.py` |
| К15 | Авторская подпись с регалиями заполнена (`author_line`) | Непустое поле фронтматтера |
| К16 | Для тем о состояниях, зависимостях, кризисах — **дисклеймер** «не заменяет консультацию специалиста» | Поиск по шаблону |
| К17 | Для тех же тем — **контакты экстренной помощи** | Поиск телефонов доверия или findahelpline |
| К18 | `python3 seo/neurocheck.py <файл>` даёт **≥80%** по строке `HUMAN(+likely) / Сегментов` | Процент из вывода, **не код выхода** — скрипт всегда возвращает 0 |
| К19 | Запрещённых формулировок **нет**: обещания результата, диагнозы, позиционирование как терапия или её замена, самоназвание «группа поддержки» | Grep по списку паттернов |
| К20 | Все истории и примеры имеют указанное происхождение; выдуманных кейсов и отзывов нет | Явное перечисление источника каждого примера |

### Порог отбраковки

**Три и более непройденных пункта — материал переписывается, а не правится.**

Один-два непройденных — точечная правка и повторный прогон чек-листа.

**Отдельно про уже опубликованные материалы.** Порог отбраковки применяется к новым текстам. У 40 статей, опубликованных до начала программы, есть накопленная индексация в Яндексе: массовое переписывание её обнулит. Для них правило другое — точечная правка, если она не затрагивает `title`, `H1` и URL; всё, что требует переписывания, идёт в бэклог `decisions.md` с приоритетом, а не переделывается сплошняком.

## 5. Правило честного объёма

Ориентир ТЗ — 240 материалов за год. **План даёт 73.**

Это не недоработка плана, а результат честной инвентаризации. Ядро из 18 принятых кластеров содержит 107 целевых запросов, из них 34 уже покрыты существующими статьями. Писать 240 материалов на 73 незанятых запроса означало бы либо по три текста на один запрос — то есть спроектированную каннибализацию, — либо изобретение запросов, которых никто не ищет.

Ниша конечна. Мужское ментальное здоровье — узкая предметная область, и это её естественный размер, а не следствие плохого ресёрча.

**Где объём может вырасти честно:**

| Источник | Даёт материалов | Условие |
|---|---|---|
| Разморозка гео (4 города) | ~20 | Устойчивый поток встреч, решение в месяце 12 |
| Смещённые углы в `depression` и `addiction` | ~10 | Полгода публикаций и накопленный траст |
| Запросы, найденные в Search Console по факту | ~15–30 | Появляются сами, когда пойдут показы: самый дешёвый и надёжный источник роста |
| Ранние триггеры отдельной линией | ~10 | Только с собственным pillar, а не свалкой хвостов |

Реалистичный потолок при выполнении всех условий — **130–145 материалов** за год.

**Правило остановки.** Если содержательная база кластера исчерпана раньше, чем покрыты все его запросы из ядра, — остановиться и записать это в `decisions.md`, а не добивать вариациями одного текста. Сорок заголовков вида «Как справиться с X» — брак, даже если формально план выполнен.

## 6. Границы и запреты

Действуют на всём горизонте программы, без исключений.

- Никаких диагнозов, обещаний результата и формулировок, позиционирующих сообщество как замену терапии или психиатрической помощи. Проверяется пунктом К19.
- Истории и отзывы участников — только согласованные. Выдуманные кейсы запрещены. Проверяется пунктом К20.
- Никаких покупных ссылок, бирж, PBN, накрутки поведенческих, генерации отзывов. Ссылочный рост — только нативный: описания видео на YouTube-канале, гостевой выпуск подкаста, питчи в диаспорные медиа.
- Бюджет не тратится, платные подписки не оформляются.
- Оценка частотности не выдаётся за факт: всё непроверенное в Wordstat помечается `[гипотеза]`.
- Работа не имитируется. Нет доступа к сервису — это пишется в `state.md` и запрашивается, а не обходится молчанием.

## 8. Допущения и риски

**Допущения.** Владелец имеет доступ к Вебмастеру и Метрике и даёт выгрузки на контрольных точках; частотность проверяет он же пачками в Wordstat; заявка считается по клику на `forms.gle` — дальше атрибуция обрывается; артефакты программы живут в `seo/`; шаблон статьи не меняется.

**Риски.**

| Риск | Вероятность | Митигация |
|---|---|---|
| Google не откроется за год | высокая | Индексация ведётся раздельно; по Google зафиксирована нетехническая причина (Р-001); ссылочный разгон нативными каналами |
| Конверсия окажется неизмеримой | средняя | Страница `/vstrecha` создана как отдельный URL, цели заведены; граница атрибуции описана честно (Р-006, Р-007) |
| Реальная частотность разойдётся с гипотезами | средняя | Батчи Wordstat готовы; порядок кластеров пересобирается задачей D2 без остановки производства |
| Объём кластеров окажется меньше даже 18 | низкая | Тест приёмки пройден каждым принятым кластером; сателлиты с различающимся интентом расписаны построчно |
| Массовые правки существующих статей обнулят индексацию | средняя | Порог отбраковки не применяется к старым материалам; склеек и удалений URL нет ни одной |
