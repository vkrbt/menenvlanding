**Код:**

| Файл | Назначение |
|---|---|
| `scripts/seo-check.py` | **Сквозной гейт качества.** 6 проверок, эталон не нужен |
| `scripts/seo-report.py` | Разбор выгрузок из `seo/data/` в таблицу по кластерам |
| `seo/gen_clusters.py` | `_core_data.py` → `content/clusters.json` |

| `lib/clusters.ts` | Кластеры для сайта |
| `app/blog/tema/[cluster]/page.tsx` | Страницы рубрик |

**Важно про генерацию.** После любой правки `seo/_core_data.py` обязательно выполнить:
```
python3 seo/gen_clusters.py && python3 seo/gen_content_plan.py
```
Иначе сайт, план и ядро разойдутся.
