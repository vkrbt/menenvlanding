
## Что следующее

**Задача E1 из [plan.md](plan.md)** — закрыть кластер `loneliness` целиком.

Начинать с: [content-plan.md](content-plan.md), раздел «Месяц 4». В кластере есть pillar (`net-druzey-posle-30`) и 3 сателлита, дописать 4 материала. Целевые запросы — в [core.md](core.md), кластер `loneliness`.

**Порядок работы над материалом** (выведен из ошибок этого прогона):

1. Проверить каннибализацию: целевой запрос против всех `target_query` в `content/blog/*.md`.
2. Написать текст.
3. **Сразу прогнать `python3 seo/neurocheck.py` — до всякой обвязки.** Ниже 80% — править текст, а не идти дальше. Паттерны, которые роняют оценку: числа прописью, перечисление «первое-второе-третье», цепочки «**Термин.** Пояснение», абстракция без конкретной детали.
4. Только после прохождения порога — фронтматтер, перелинковка, CTA, блок помощи.
5. Прогнать чек-лист из [plan.md](plan.md) §4, затем `npm run build` и `python3 scripts/seo-check.py`.
6. Обновить `seo/_core_data.py`, затем **обязательно** `python3 seo/gen_clusters.py && python3 seo/gen_content_plan.py`.

Параллельная задача с высоким приоритетом — переписывание 17 отложенных черновиков (Р-019). По объёму это равно написанию заново, ставить в очередь наравне с новыми материалами.
