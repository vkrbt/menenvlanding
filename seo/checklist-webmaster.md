# Чек-лист панелей вебмастера

Действия, которые может выполнить только владелец — они требуют входа в аккаунт. Каждый шаг проверяемый: рядом указано, что должно появиться на экране.

Адрес карты сайта везде один: **`https://sreda.men/sitemap.xml`** (43 URL на 2026-07-29).

---

## 1. Google Search Console — приоритет первый

Верификационный метатег на сайте уже стоит (`app/page.tsx`), поэтому домен, скорее всего, подтверждён. Нужно проверить остальное.

1. Открыть [search.google.com/search-console](https://search.google.com/search-console) и выбрать ресурс `sreda.men`.
   - _Если ресурса нет в списке:_ «Добавить ресурс» → **Префикс URL** → `https://sreda.men` → способ подтверждения «Тег HTML». Тег уже на сайте — нажать «Подтвердить».
2. Слева «Файлы Sitemap» → в поле ввода `sitemap.xml` → «Отправить».
   - _Что должно появиться:_ строка со статусом **«Успешно»** и числом обнаруженных URL. Если статус «Не удалось прочитать» — прислать мне точную формулировку ошибки.
3. Слева «Страницы» (раздел «Индексирование»).
   - _Записать и прислать:_ сколько страниц в блоке «Проиндексировано» и сколько в «Не проиндексировано», а **главное — список причин** из таблицы внизу. Ключевые формулировки: «Обнаружено — не проиндексировано», «Просканировано — не проиндексировано», «Страница-дубликат», «Заблокировано в файле robots.txt».
   - Это единственные данные, отделяющие вердикт фазы 1 от полной определённости.
4. Вверху строка поиска по URL → вставить `https://sreda.men/blog/vygoranie-u-muzhchin` → Enter.
   - _Записать:_ что говорит «Проверка URL» — «URL есть в Google» или «URL нет в Google», и что в блоке «Сканирование».
   - Если «URL нет в Google» — нажать **«Запросить индексирование»**. Повторить для `https://sreda.men` и `https://sreda.men/blog`.
5. Слева «Ссылки» → записать общее число внешних ссылок.
   - _Ожидание:_ близко к нулю. Это подтверждает вердикт о причине.

## 2. Яндекс.Вебмастер — здесь индексация уже идёт, нужны данные

1. Открыть [webmaster.yandex.ru](https://webmaster.yandex.ru), выбрать `sreda.men`.
2. «Индексирование» → «Страницы в поиске».
   - _Записать:_ сколько страниц в поиске, динамика за последний месяц.
   - Внизу кнопка выгрузки — **скачать XLS/CSV и положить в `seo/data/`** (директорию создам в фазе 6).
3. «Индексирование» → «Файлы Sitemap» → убедиться, что `https://sreda.men/sitemap.xml` есть в списке и статус «Успешно». Если нет — добавить.
4. «Поисковые запросы» → «Управление группами» → период «последние 90 дней».
   - _Записать:_ показы, клики, средняя позиция. Выгрузку — в `seo/data/`.
   - Даже нулевые цифры полезны: это точка отсчёта.
5. «Индексирование» → «Переобход страниц» → отправить главную, `/blog` и 3–5 статей.

---

## 3. Bing Webmaster Tools — дешёвый шаг, делается один раз

1. Открыть [bing.com/webmasters](https://www.bing.com/webmasters).
2. «Add a site» → есть кнопка **«Import from Google Search Console»** — это самый быстрый способ, подтверждение подтянется автоматически.
   - _Если импорт не сработал:_ подтверждение через метатег — пришли мне выданный код, я добавлю его в `app/page.tsx` рядом с существующими.
3. «Sitemaps» → «Submit sitemap» → `https://sreda.men/sitemap.xml`.

## 4. Яндекс.Метрика — нужны цели, без них конверсия не считается

Счётчик на сайте стоит (`components/YandexMetrika.tsx`), но целей нет — значит клики по CTA сейчас нигде не фиксируются.

1. Открыть [metrika.yandex.ru](https://metrika.yandex.ru) → счётчик `sreda.men` → «Настройка» → вкладка «Цели».
2. Создать цели. Точные имена задам в фазе 5 — вернусь с ними отдельным списком; создавать заранее не нужно.
3. Проверить, что «Вебвизор» включён: «Настройка» → «Вебвизор, аналитика форм» → переключатель. Для страницы встречи это самый ценный источник — видно, где человек уходит.
