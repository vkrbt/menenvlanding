# Задача: психологические самотесты по мужской тематике

**Статус:** backlog (записано 2026-07-10, отдельная сессия)
**Зачем:** самотест — самая низкопороговая точка входа мужчины в воронку. Данные ресёрча ([seo/02-audience-research.md](../seo/02-audience-research.md)): 500 000+ прохождений Self Check на HeadsUpGuys, 85 000 «head inspection» на Man Therapy; анонимный чек-лист конвертирует «просто читаю» → «признаю проблему» лучше любого контента.

## Что сделать

1. **Найти механики и валидированные методики** (со свободной лицензией, с валидированными русскими версиями где есть):
   | Тема | Кандидаты | Лицензия |
   |---|---|---|
   | Депрессия | PHQ-9; мужская специфика — MDRS-22 | PHQ-9 public domain; MDRS — проверить |
   | Тревога | GAD-7 | public domain |
   | Выгорание | CBI (Copenhagen Burnout Inventory) или OLBI | свободные; **MBI лицензируется — не брать без лицензии** |
   | Алкоголь | AUDIT / AUDIT-C, CAGE | ВОЗ, свободные |
   | Порнозависимость | PPCS / BPS | проверить лицензии |
   | Одиночество | UCLA Loneliness Scale (3-item) | свободная |
   | Эмиграция/адаптация | готовой методики может не быть → честный чек-лист самонаблюдения без псевдонаучных претензий | — |

2. **Реализация:** статические страницы `/tests/...` в стиле сайта (классы `.article` из main.css), подсчёт на клиентском JS **без отправки данных** (анонимность — часть оффера), интерпретация по валидированным порогам.

3. **Обязательно:**
   - дисклеймер «скрининг, не диагноз, не заменяет консультацию специалиста»;
   - при высоких баллах по депрессии — блок контактов экстренной помощи;
   - CTA → заявка в сообщество (forms.gle/tvTnJuyBoedpJZ989); позиционирование «сообщество/клуб», не «группа поддержки»;
   - SEO: title/description/canonical/JSON-LD (Quiz/Article, не MedicalWebPage), страницы в sitemap.xml, перелинковка с блогом и главной.

4. Перед реализацией — план и выбранные методики зафиксировать в `plans/tests-plan.md`.
