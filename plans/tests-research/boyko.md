# Методика диагностики уровня эмоционального выгорания (В.В. Бойко)

Исследование подготовлено к кодированию онлайн-самотеста. Дата: 2026-10-09.

**Главный вывод.** Книги самого Бойко (1996, 1999, 2004, 2008) в открытом доступе нет, поэтому сверить ключ с авторским текстом не удалось. Ключ проверен по трём книжным перепечаткам. Две из них сверены по изображению страницы: Райгородский 2001 и Водопьянова–Старченкова 2008. Третья — Ильин 2011, текстовая перепечатка. Ещё сверены методичка КНИТУ 2012 и 11 сайтов. **Во всех книжных источниках одинаковая структурная ошибка:** в симптоме «Личностная отстраненность» стоит `+72(2)` вместо ожидаемого `+71(2)`. Из-за этого пункт 72 считается дважды, а пункт 71 не считается нигде. Вторая находка, которую в рунете не обсуждают: при весах из книг максимум этого симптома **33**, а не 30, как пишут все источники. Пороги симптомов (≤9 / 10–15 / ≥16) и фаз (≤36 / 37–60 / ≥61) подтверждены книжными источниками и совпадают везде.

Уровни уверенности: **В** — высокая (≥2 книжных источника, сверено по изображению), **С** — средняя (одна книга или вывод из структуры), **Н** — низкая (только сайты или не подтверждено).

## Подсчёт и пороги

**Порядок (R01, с. 166, дословно):** «1) определяется сумма баллов раздельно для каждого из 12 симптомов «выгорания», 2) подсчитывается сумма показателей симптомов для каждой из 3-х фаз формирования «выгорания», 3) находится итоговый показатель синдрома «эмоционального выгорания» — сумма показателей всех 12-ти симптомов.» То же в VS08, IL11 и KN12. Уверенность **В**.

**Пороги симптома (R01, с. 167–168; = IL11, KN12, PL, psyh.info):**

| Баллы симптома | Уровень |
|---|---|
| ≤ 9 | не сложившийся симптом |

|---|---|

**Оговорка автора (R01, дословно):** «сопоставление баллов, полученных для фаз, не правомерно, ибо не свидетельствует об их относительной роли или вкладе в синдром… По количественным показателям правомерно судить только о том, насколько каждая фаза сформировалась». ## Рекомендация для кода

1. **Ключ** — таблица «Итоговый ключ для кода» выше. Ответ «да» = 1, «нет» = 0. Для каждого пункта начисляется вес из колонки, совпадающей с ответом.
2. **Пункты 71/72.** Рекомендую `+71(2)` в И3 и `+72(10)` только в И4. Основания:
   - во всех 12 строках действует правило шага 12, а печатный ключ его нарушает только здесь;
   - иначе один пункт бланка не учитывается, а другой учитывается дважды, хотя в методике нет ни одного пункта с двойным счётом;
   - содержание 71 («работа с людьми разочаровала») относится к деперсонализации, содержание 72 («принимаю лекарства») — к психосоматике.
   
   **Цена решения:** результат может отличаться от ручного подсчёта «по бумажному ключу» Райгородского или Водопьяновой не больше чем на 2 балла в И3 и в фазе «Истощение», и только если ответы на 71 и 72 различаются (векторы V6, V7). Если владельцу важнее буквальное совпадение с печатным ключом — поставить флаг `BOYKO_PRINTED_KEY_72 = true`: И3 тогда берёт пункт 72 вместо 71. Решение за владельцем (см. «Открытые вопросы»).
3. **Пункт 11** — оставить вес 5 (R01, VS08, IL11 и большинство сайтов). Вес 2 есть только в ветке KN12 (методичка).
4. **Пункт 42** — формулировка «на «хороших» и «плохих»».
5. **Уровни:** симптом ≤9 / 10–15 / ≥16 плюс флаг «доминирующий» при ≥20. Фаза ≤36 / 37–60 / ≥61. Итоговый показатель выводить числом без уровня: порогов у автора нет. **Не** объявлять «ведущую фазу» по максимуму.
