# STAI в адаптации Ю.Л. Ханина (шкала реактивной и личностной тревожности): доказательная справка для онлайн-самотеста

Дата сбора: 2026-10-09. Тексты пунктов, ключи и пороги ниже **скопированы из скачанных документов** (curl → разбор HTML/PDF). По памяти ничего не восстанавливала. Уровни уверенности:
- **В** — высокий: рецензируемая статья или официальный документ, текст видела сама;
- **С** — средний: монография, учебник или сайт, сверенные с несколькими другими источниками;
- **Н** — низкий: не проверено или источники противоречат друг другу.

**Главное.** Брошюру Ханина 1976 года найти не удалось ни в одном открытом источнике. Поэтому «канон» восстановлен методом триангуляции:
1. структура оригинала Form X (Spielberger et al., 1970);
2. рецензируемые российские работы, которые использовали версию Ханина и приводят её ключ и формулировки пунктов (Мерзляков, 2026);
3. официальные клинические рекомендации Минздрава;
4. несколько независимых перепечаток.

По ключу и константам всё сходится (В). По дословному тексту ряда пунктов и по порогу «45 или 46» единого канона нет (см. §5 и §6).

## 2. Текст пунктов

### 2.0. Две редакции текста, которые ходят под именем Ханина

- **Редакция A** (W1–W6, W8, R8 и цитаты в рецензируемой R2) по смыслу пункт-в-пункт соответствует **Form X**: regretful → «испытываю сожаление», rested → «отдохнувшим», I feel pleasant → «испытываю удовольствие», I feel secure → «в безопасности», «I take disappointments so keenly…» → «Я так сильно переживаю свои разочарования…». Её же используют рецензируемые работы (R2). **Рекомендую её.** Уверенность: В по структуре, С по дословности.
- **Редакция B** (W7: Батаршев, Дерманова, Прохоров; Минздрав R6/R7; W9) — переработанный текст. В ЛТ переписаны десять пунктов (21, 22, 23, 25, 26, 28, 30, 33, 36, 38), а 33 «Я чувствую себя беззащитным» стал **прямым по смыслу** (в оригинале «I feel secure» — обратный). Откуда взялась эта редакция, установить не удалось: в первоисточнике Ханина её подтвердить нельзя. Для сайта **не использовать**.

### 2.1. Инструкции (редакция A, дословно по cmrvsm, painmed и ppms22; совпадает с W2)

- **РТ:** «Прочитайте внимательно каждое из приведенных ниже предложений и зачеркните цифру в соответствующей графе справа в зависимости от того, как вы себя чувствуете в ДАННЫЙ МОМЕНТ. Над вопросами долго не задумывайтесь, поскольку правильных и неправильных ответов нет. Обычно первый ответ, который приходит в голову, является наиболее правильным, адекватным Вашему состоянию.»
- **ЛТ:** «Прочитайте внимательно каждое из приведенных ниже предложений и зачеркните цифру в соответствующей графе справа в зависимости от того, как вы себя чувствуете ОБЫЧНО.» В R6 и W4 добавлено: «Над вопросами долго не думайте, поскольку правильных или неправильных ответов нет.»

Эмпирика подтверждает ключ. В ЭФА R2 (n = 997) п. 13 «Я не нахожу себе места» попал в фактор прямых пунктов, а п. 15 — в фактор обратных. Значит, вариант Минздрава, где 13 и 15 поменяны местами, — ошибка.

### 3.2. Формулы (В)

- **РТ = Σ1 − Σ2 + 50** (Σ1 — прямые, Σ2 — обратные). Источники: S1 (+50 для State в Form X), R6/R7 (формула-картинка, константа в тексте не видна), W2, W8, sem-psiholog (по сниппету).
- **ЛТ = Σ1 − Σ2 + 35.** Источники: S1 (+35 для Trait), W2, W3, W4, W5, W8.

**Проверка диапазона:**
- РТ: min = 10·1 − 10·4 + 50 = **20**; max = 10·4 − 10·1 + 50 = **80**.
- ЛТ: min = 13·1 − 7·4 + 35 = **20**; max = 13·4 − 7·1 + 35 = **80**.
- Для сравнения: с константой +35 для РТ (W3, W4, W5) диапазон получается 5–65, что противоречит заявленным в тех же источниках «20–80». Это прямое доказательство ошибки.

### 3.3. Эквивалентность с инверсией (5 − x) (В, алгебраически)

Для любого набора ответов:

Σ_прям x + Σ_обр (5 − x) = Σ_прям x − Σ_обр x + 5·n_обр

- РТ: n_обр = 10, поэтому 5·10 = **50**;
- ЛТ: n_обр = 7, поэтому 5·7 = **35**.

Значит, формулы совпадают **для каждого конкретного ответа**, а не только по диапазону. Константы Ханина — это просто 5 × число обратных пунктов. Так же описан подсчёт в S1: «In effect, the procedure automatically reverses the response weight…». Схему инверсии использует и R4: «1 балл = 4 балла, 2 = 3, 3 = 2, 4 = 1», затем сумма.

## 6. Рекомендация для кода

1. **Текст:** редакция A, вариант Беловой/psytests (§2.3 + столбец W1 в §2.4). Это единственный вариант, чьи формулировки подтверждаются рецензируемой работой (R2). Альтернатива — «ядро» cmrvsm/painmed: тоже редакция A, разница стилистическая. Пункт 33 — «Обычно я чувствую себя в безопасности». Редакцию B не использовать.
2. **Род.** Исходный текст в мужском роде; аудитория sreda.men — мужчины, менять ничего не нужно. Если понадобится женская форма, у psytests есть «женский бланк» (W1), и это допустимая грамматическая адаптация.
3. **Варианты ответа:** РТ — «Нет, это не так / Пожалуй, так / Верно / Совершенно верно» (1–4); ЛТ — «Почти никогда / Иногда / Часто / Почти всегда» (1–4).
4. **Инструкции:** две отдельные, «в данный момент» и «обычно» (§2.1). Сами части подаются раздельно, сначала РТ.
5. **Подсчёт** — инверсией. Так проще и не нужно отдельно хранить константы:
   ```js
   const REV_STATE = [1, 2, 5, 8, 10, 11, 15, 16, 19, 20];   // 10
   const REV_TRAIT = [21, 26, 27, 30, 33, 36, 39];           // 7
   // ans[i] ∈ {1,2,3,4}, i = 1..40
   const score = (from, to, rev) => {
     let s = 0;
     for (let i = from; i <= to; i++) s += rev.includes(i) ? 5 - ans[i] : ans[i];
     return s; // 20..80
   };
   const RT = score(1, 20, REV_STATE);
   const LT = score(21, 40, REV_TRAIT);
   ```
   Добавить ассерты: 20 ≤ score ≤ 80; все 40 ответов заполнены, частичный подсчёт не делать. Тестовые векторы взять из §3.4.
6. **Пороги:** выбрать один вариант и указать источник прямо на странице результата. Моё предложение — **≤ 30 / 31–44 / ≥ 45 (вариант I, клинические рекомендации Минздрава РФ)**. Это действующий официальный документ, и на балле 45 он консервативнее, то есть безопаснее для самотеста: человек с пограничным баллом скорее получит совет обратиться к специалисту. Подпись под порогами: «ориентировочные градации по клиническим рекомендациям Минздрава РФ; первоисточник — Ханин, 1976». Окончательный выбор между 45 и 46 — за владельцем продукта, см. §7.
7. **Выводить обе шкалы отдельно.** Не складывать их и не показывать «общий балл»: в источниках его нет.
8. **Дисклеймер:** методика рассчитана на взрослых (R5: стандартизирована на 20–22-летних; для подростков нужны свои нормы). Это скрининг самооценки, а не диагноз.
9. **Не путать** с STAI-T Тихомировой (2025), STAI-10 Мерзлякова (2026) и STAI-8 Брагина (2023). Это отдельные инструменты со своими ключами и порогами.

## 7. Открытые вопросы

1. **Брошюра Ханина 1976 недоступна.** Поэтому дословный «канонический» текст, исходный порог (45 или 46) и происхождение редакции B не установлены. Где искать дальше: библиотека НГУ им. Лесгафта (бывший ЛНИИФК), РНБ, МБА. Ещё один кандидат — глава Hanin & Spielberger (1983) в *Cross-Cultural Anxiety*, Vol. 2.
2. **Книгу Беловой (2002/2018) не видела.** Совпадение текста psytests с ней — моё предположение по ссылке и по цитатам в R2.
3. **Права.** STAI (Form X и Y) защищён авторским правом, правообладатель Mind Garden продаёт лицензии на администрирование и переводы. Mind Garden указывает переводы «Russian» и «Russian–Estonia», но их содержание, форма (X или Y) и валидация неизвестны. Как русская версия Ханина соотносится с правами Mind Garden, неясно: её широко перепечатывают, в том числе Минздрав. Если сайт коммерческий, юридический статус стоит проверить отдельно (это не юридическая консультация).
4. **Официальный русский STAI-Y.** Опубликованной русской валидации Form Y я не нашла. Поиск: PubMed, cyberleninka через Google, Mind Garden. Форма Y меняет состав ЛТ (9 обратных: 21, 23, 26, 27, 30, 33, 34, 36, 39) и часть формулировок. **Ключ Form Y к тексту Ханина применять нельзя.**
5. **Нормы Зайцева и Хвана (2011):** без подписей столбцов РТ/ЛТ таблицу использовать нельзя. Нужен оригинал журнала «Психологическая диагностика», 2011, № 3.
6. **Тождество приложения КонсультантПлюс (COVID-19) и PDF cmrvsm** не проверено: КонсультантПлюс открывается только по расписанию.
7. **Психометрия русской версии.** По R2 и R4, обратные пункты образуют отдельный фактор, а пп. 2 и 33 нагружают факторы слабо или никак. Это ограничение самого инструмента, а не ошибка кода. Упомянуть ли его в тексте страницы — решение редакции.

## 8. Проверка КР Минздрава (2026-10-09)

**Итог: подтверждается полностью (В).** В обоих документах, КР457 и КР455, в ключе РТ пункт 15 стоит среди прямых, а пункт 13 среди обратных. В каноне наоборот. Пункт 33 в ЛТ сформулирован как «беззащитным», но в ключе стоит среди обратных (E4). Для РТ даны варианты ответа на частоту без «Иногда» (E9). Тексты КР457 и КР455 в этой части совпадают дословно.

**Где смотрела.** Оба документа открылись, тексты скачаны curl'ом:
- официальный API рубрикатора: [apicr.minzdrav.gov.ru, id=457_2](https://apicr.minzdrav.gov.ru/api.ashx?op=GetClinrec2&id=457_2&ssid=) («Генерализованное тревожное расстройство», version 2, created 2021-09-16, NPC_approved: true) и [apicr.minzdrav.gov.ru, id=455_2](https://apicr.minzdrav.gov.ru/api.ashx?op=GetClinrec2&id=455_2&ssid=) («Тревожно-фобические расстройства у взрослых», version 2, created 2021-09-16, NPC_approved: true). Версии `_1` отдают 403. Здесь формулы записаны **текстом**, а не картинкой;
- копии на sudact (ссылки из R6/R7): [КР457 Г5, ключ](https://sudact.ru/law/klinicheskie-rekomendatsii-generalizovannoe-trevozhnoe-rasstroistvo-utv-minzdravom/prilozhenie-g1-gn/prilozhenie-g5/shkala-lichnoi-trevozhnosti/kliuch-interpretatsiia_4/), [КР457 Г5, РТ](https://sudact.ru/law/klinicheskie-rekomendatsii-generalizovannoe-trevozhnoe-rasstroistvo-utv-minzdravom/prilozhenie-g1-gn/prilozhenie-g5/shkala-situativnoi-trevozhnosti/), [КР457 Г5, ЛТ](https://sudact.ru/law/klinicheskie-rekomendatsii-generalizovannoe-trevozhnoe-rasstroistvo-utv-minzdravom/prilozhenie-g1-gn/prilozhenie-g5/shkala-lichnoi-trevozhnosti/), [КР455 Г4](https://sudact.ru/law/klinicheskie-rekomendatsii-trevozhno-fobicheskie-rasstroistva-u-vzroslykh-utv/prilozhenie-g1-gn/prilozhenie-g4/). Списки пунктов и пороги совпадают с API. Формулы на sudact — картинка; на картинке видно «= − +50».

**Дословно (одинаково в API 457_2 и 455_2):**

> Уровень реактивной тревожности вычисляется по формуле: ТР = ∑рп - ∑ро + 50, где: ТР – показатель реактивной тревожности; ∑рп – сумма баллов по прямым вопросам (3, 4, 6, 7, 9, 12, 14, 15, 17, 18); ∑ро – сумма баллов по обратным вопросам (1, 2, 5, 8, 10, 11, 13, 16, 19,20).

> Для исчисления уровня личностной тревожности применяется формула: ТЛ = ∑лп - ∑ло + 35, где: ТЛ– показатель личностной тревожности; ∑лп – сумма баллов по прямым вопросам (22, 23, 24, 25, 28,29,31,32,34,35,37,38,40); ∑ло – сумма баллов по обратным вопросам (21, 26, 27, 30, 33, 36, 39).

> Интерпретация до 30 баллов – низкая тревога (тревожность), 31 - 44 балла – умеренная; 45 и более – высокая.

Пункты из бланков:
- РТ п. 13: «Я не нахожу себе места». По смыслу это прямой пункт, в ключе КР стоит среди обратных.
- РТ п. 15: «Я не чувствую скованности, напряжения». По смыслу обратный, в ключе КР стоит среди прямых.
- ЛТ п. 33: «Я чувствую себя беззащитным». По смыслу прямой, в ключе КР стоит среди обратных.

Внутри документа текст и ключ противоречат друг другу во всех трёх местах.

Варианты ответа. Шапка таблицы РТ: «Прочитайте внимательно каждое из приведенных ниже предложений и зачеркните цифру в соответствующей графе справа в зависимости от того, как Вы себя чувствуете в данный момент. … № пп Суждение Никогда Почти никогда Часто Почти всегда».
