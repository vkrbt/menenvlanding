# Доступные инструменты (обнаружено 2026-07-29)

| Инструмент | Статус | Где применяется |
|---|---|---|
| `WebSearch` / `WebFetch` | доступны (отложенные, через ToolSearch) | Проверка выдачи по кластерам, поиск первоисточников исследований, сверка конкурентов |
| Скилл `humanizer-ru` | доступен | Проверка новых материалов на машинность перед публикацией |
| `seo/neurocheck.py` (локальный) | доступен | Порог HUMAN ≥80% сегментов, обязательный гейт публикации |
| `npm run build` | доступен | Обязательная команда каждой фазы, затрагивающей код или контент |
| `npm run verify` (`scripts/verify-parity.mjs`) | доступен | Паритет вёрстки после правок рендера |
| `scripts/verify-seo.py` | доступен | Проверка метатегов и разметки |
| `git` + push в `main` → Vercel | разрешён владельцем | Публикация материалов |
| Context7 | не обнаружен | — |
| Яндекс.Вебмастер API / Метрика API / Wordstat API | токенов нет | Данные приходят выгрузками от владельца |
| Google Search Console | статус неизвестен (фаза 1 выясняет) | — |
| MCP: Google Drive, Figma | доступны, к задаче не относятся | — |
| MCP: Gmail, Google Calendar | требуют авторизации, недоступны в этой сессии | — |
